# 記事共通バナーの初期表示修正（2026-10-07）

## 原因と変更

本番の `rakuten-banners/article-top.json` は未保存で、公開記事2件のHTMLにはバナーがなかった。記事共通枠に初期バナーが登録されていないため、未設定時の公開状態がオフとなっていた。

TOPで指定されている楽天バナーを記事共通枠の初期値にも登録し、未設定の通常の記事で公開オンにした。TOPと記事共通の保存先は独立している。管理者が明示的に保存した公開オフ、個別バナー、記事だけ非表示、破損時の非表示は既存の扱いを維持する。

## 確認

- `npm run test:rakuten`：56件成功。未保存時の公開オン、共通バナーの差し替え、明示的な公開オフの保存・再取得、個別バナーの独立性、継承への復帰を確認。
- `npm run lint`：成功。
- production build：成功。Auth・Storage・楽天APIはローカルfixtureを使用し、本番データへの書き込みはない。
- ローカルの公開記事2件：共通バナー未保存で、指定済み画像・リンクを各1枚出力。PR表記、画像サイズ468×60、別タブ・スポンサー属性を確認。Storageへの書き込み0件。結果は `local.json`。
- 今回はブラウザ接続が利用できないため、ブラウザでの見た目の再確認は未実施。表示コンポーネントと配置・CSSは変更していない。
