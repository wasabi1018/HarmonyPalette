# 混雑予想ページの実装検証

ローカルのPGliteと公開XMLのテスト用コピーを使用。本番DBへのマイグレーション・書き込み・デプロイは行っていない。画像の混雑度、予定、気温等は検証用で、実際の来園案内として使用しない。

- `desktop-full.png`：PC、10月・19日選択。選択日詳細、予定の未公開案内を確認。
- `mobile-calendar.png`：スマホのカレンダー。スケジュール未公開案内は上部に集約。
- `mobile-modal.png`：初回比較。天気と混雑度が別行で、見本よりモーダルが高かった。
- `mobile-modal-final.png`：天気と混雑度を同じ行に修正し、余白を調整。Tabの循環と背景スクロール固定、Esc・背景タップで閉じる操作を確認。
- `mobile-comparison-before.png` / `mobile-comparison-final.png`：見本と実装を同じ390px幅に正規化して比較。天気はモックの晴れではなく実XML由来のくもりを表示している。
- `admin-saved.png`：平日の基準点を25→26へ変更し、プレビュー→保存→再取得で26を確認。最終プレビューは検証サーバーを初期化し25へ戻す。
- `admin-preview.png`：月選択とスクロール可能な点数の内訳表。
- `daily-weather.png`：日ごとの予定上部に、混雑度・天気・気温・時間帯別降水確率と出典を表示。

APIとSQLの検証は `npm run test:crowd-forecast`。公開GETが天気取得・計算・DB書き込みを起こさないこと、公開レスポンスに点数や内部メモが含まれないこと、1日1回の取得・同時更新・RLS・revision競合を確認している。
