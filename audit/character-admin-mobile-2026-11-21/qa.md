# キャラクター管理のスマホ文字崩れ修正

## 変更

- スマホではキャラクター情報と操作を2段に分け、名前・よみがな・誕生日の幅を確保する。
- 表示順の入力幅はラベル側で制限し、共通入力スタイルの `w-full` と `w-20` の競合を解消する。
- 長い名前は自然に折り返し、誕生日とアイコンは1行を維持する。
- スマホの編集・削除は44pxの操作領域とする。管理サイドバーで幅が狭まる1024pxでは一覧を1列にし、1280px以上で2列にする。

- 幅320 / 375 / 390 / 430 / 640 / 768 / 1024 / 1280 / 1440pxで、ページ・カードの横はみ出しなし、情報幅100px以上、誕生日のはみ出しなし。
- 390pxの変更前では情報幅41pxに縮む現象を再現。変更後はスマホで情報と操作が重ならない。
- 長い名前、誕生日未登録、6桁の表示順を確認。
- 検索、検索結果なし、編集フォーム開閉、表示順のPATCH送信、削除キャンセルをローカルfixtureで確認。
- ブラウザのJavaScriptエラー・console error/warningなし。

計測値は `metrics.json`、画像は `390-before.png`、`320-after.png`、`390-after.png`、`1024-after.png`、`1440-after.png` に保存。
