# 記事管理と画像処理

## Tiptap

`components/admin/article-editor.tsx`で記事のリッチテキスト編集に使用します。Starter Kitに加えて、色、画像、リンク、プレースホルダー、文字スタイル、下線を利用しています。

編集結果をそのまま安全な公開HTMLとはみなしません。保存・公開境界で検証と無害化を行います。

画像レイアウトは `lib/articles/layout.ts` の専用Nodeで、写真＋文章の左右配置と写真2枚の配置を保持します。2つのColumnと画像・代替テキスト・キャプションをJSONに保存し、HTMLでは `data-article-layout`、`data-article-layout-column`、`figure[data-article-image]` に出力します。`components/admin/article-layout.tsx` は編集時だけの操作UIです。左右入れ替えと解除は既存の内容を保持し、640px以下では公開画面・編集画面とも縦に並びます。空の写真枠は品質チェックの対象ですが、下書き保存は可能です。

文字色・リンク・画像レイアウトの選択パネルはReact Portalで本文の前面に表示します。横スクロールするツールバーの外へ出すことで切れを防ぎ、画面端・スクロール・モバイルの表示領域に合わせて位置を調整します。

## sanitize-html

`lib/articles/validation.ts`と`lib/articles/publishing.ts`で、記事HTMLの許可要素・属性を検証し、危険または不要な内容を除去します。許可設定を変更すると、既存記事の表示と保存結果に影響するため、代表的な本文で確認します。

## Sharp

`lib/articles/image-optimization.ts`で記事画像を検査・変換します。また、`scripts/compress-existing-article-images.ts`やガイド画像生成スクリプトでも使用します。

主な確認項目は、画像形式、寸法、アニメーション、圧縮品質、透過、ファイルサイズです。

## Supabaseとの関係

- 記事本文、SEO、タグ、シリーズ、状態、改訂情報：Supabase Database
- 記事画像本体：Supabase Storage
- 画像参照とメタデータ：Supabase Database

## ライフサイクル

```text
下書き → レビュー・品質確認 → 予約または公開
   └→ 改訂履歴
公開済み → ゴミ箱 → 復元または完全削除
```

公開記事詳細とsitemapの記事一覧は、公開記事タグ付きの24時間キャッシュを使用します。記事、タグ、シリーズ、公開状態を変更したときは`revalidatePublicArticleData`から同じタグと関連パスを無効化し、DBの一時障害時に不完全なsitemapや汎用メタデータを正常応答として残さないようにします。

記事機能の変更では、一覧、詳細、プレビュー、フィード、シリーズ、検索、関連コンテンツ、画像代替テキスト、SEOを影響範囲に応じて確認します。
