# 記事管理と画像処理

## Tiptap

`components/admin/article-editor.tsx`で記事のリッチテキスト編集に使用します。Starter Kitに加えて、色、画像、リンク、プレースホルダー、文字スタイル、下線を利用しています。

編集結果をそのまま安全な公開HTMLとはみなしません。保存・公開境界で検証と無害化を行います。

## sanitize-html

`lib/articles/validation.ts`と`lib/articles/publishing.ts`で、記事HTMLの許可要素・属性を検証し、危険または不要な内容を除去します。許可設定を変更すると、既存記事の表示と保存結果に影響するため、代表的な本文で確認します。

## Sharp

`lib/articles/image-optimization.ts`で記事画像を検査・変換します。また、`scripts/compress-existing-article-images.ts`やガイド画像生成スクリプトでも使用します。

主な確認項目は、画像形式、寸法、アニメーション、圧縮品質、透過、ファイルサイズです。

## Supabaseとの関係

- 記事本文、SEO、タグ、シリーズ、状態、改訂情報：Supabase Database
- 記事画像本体：Supabase Storage
- 画像参照とメタデータ：Supabase Database

## ライフサイクル

```text
下書き → レビュー・品質確認 → 予約または公開
   └→ 改訂履歴
公開済み → ゴミ箱 → 復元または完全削除
```

記事機能の変更では、一覧、詳細、プレビュー、フィード、シリーズ、検索、関連コンテンツ、画像代替テキスト、SEOを影響範囲に応じて確認します。
