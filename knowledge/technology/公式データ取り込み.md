# 公式データ取り込み

## 目的

ハーモニーランドとFan Studioの公式情報を取得し、出典を保持したレビュー可能な候補へ変換します。取得結果を無条件で公開データにしません。

## 技術と利用場所

| 技術 | 用途 | 主な場所 |
| --- | --- | --- |
| PDF.js | PDFの読み込みとページ処理 | `lib/official-import/pdf.ts` |
| napi-rs/canvas | Node.js上でPDFページを描画 | `lib/official-import/pdf.ts` |
| Tesseract.js | 画像内の時刻・名称のOCR | `lib/official-import/funstudio.ts` |
| Sharp | 切り出し、拡大、グレースケール、鮮明化 | `lib/official-import/funstudio.ts` |
| TypeScript parser | 日付・時刻・名称・イベントの正規化 | `lib/official-import/` |
| Supabase Repository | 候補、差分、レビュー、公開 | `lib/supabase/schedule-repository.ts`など |

`next.config.mjs`では、これらのネイティブ・重量パッケージをサーバー外部パッケージとして扱い、PDF workerをRoute Handlerの出力追跡に含めています。

## 処理段階

1. 取得元URL、対象日、形式を記録する。
2. PDFまたは画像を読み込む。
3. 必要な領域を描画・切り出し・画像処理する。
4. OCRまたはparserで文字・時刻を抽出する。
5. キャラクター名、日付、時刻、欠損値を正規化する。
6. 既存データと比較し、候補と差分を作る。
7. 管理者がレビューする。
8. 明示的な許可がある場合だけ永続化・公開する。

## 安全条件

- 不確かな時刻や名称を推測で確定しない。
- 取得元URLと日付の追跡性を失わない。
- 最初は狭い日付範囲のプレビューで確認する。
- `--persist`は明示的な依頼なしで追加しない。
- 自動公開より候補・レビューを優先する。

## 確認

対象parserのテスト、実データに近いfixture、非永続プレビュー、重複、欠損、休止・中止、日付境界、名称表記揺れを確認します。
