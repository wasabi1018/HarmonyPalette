# 技術構成マップ

## 全体

| レイヤー | 技術 | 主な役割 |
| --- | --- | --- |
| UI・ページ | Next.js 15、React 19、TypeScript | 公開サイト、管理画面、Route Handler |
| スタイル | Tailwind CSS、PostCSS | レスポンシブUI、デザイントークン |
| データ | Supabase Database、Auth、Storage | 運用データ、認証、記事画像 |
| 記事編集 | Tiptap、sanitize-html | リッチテキスト編集、検証、無害化 |
| 予定操作 | dnd-kit、html-to-image | My Plan並べ替え、画像書き出し |
| 公式取り込み | PDF.js、napi-rs/canvas、Tesseract.js、Sharp | PDF描画、OCR、画像前処理、正規化 |
| 品質 | ESLint、TypeScript strict、Node test runner、tsx | 静的検査、型検査、単体テスト |
| 配信 | Vercel、Next.js Cron Route | Web配信、記事予約公開 |

## 技術を追加・変更するとき

技術名だけではなく、採用理由、利用場所、ブラウザかサーバーか、扱うデータ、障害時の影響、確認方法を更新します。依存バージョンの正本は`package.json`です。
