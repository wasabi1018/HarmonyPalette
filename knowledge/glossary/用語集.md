# 用語集

| 用語 | このプロジェクトでの意味 |
| --- | --- |
| 正本 | 最終的に正しいとみなす情報源。情報の種類ごとに異なる |
| 候補 | 公式情報から取得したが、まだ承認・公開されていないデータ |
| 永続化 | プレビュー結果などをSupabaseへ保存すること |
| Repository | Supabaseの行とアプリケーションの型・処理を分離する境界 |
| RLS | Supabase PostgreSQLのRow Level Security。行単位のアクセス制御 |
| Route Handler | Next.jsの`app/api/`でHTTP処理を実装する仕組み |
| Server Component | サーバー側で実行されるReactコンポーネント |
| Client Component | `"use client"`を持ちブラウザで状態・イベントを扱うコンポーネント |
| Migration | DB構造を履歴として変更するSQLファイル |
| OCR | 画像内の文字を認識する処理。Fan Studio取り込みで使用 |
| ADR | Architecture Decision Record。重要な設計判断と理由の記録 |
| Vault | Obsidianが管理するローカルフォルダ。このプロジェクトでは`knowledge/` |
| QA証跡 | 実装結果を確認する画面キャプチャ、比較画像、検証記録 |
