# 推しキャラおすすめ日画像

## 目的

Instagramでコメントされた推しキャラクターに対して、対象月で登場予定が多い日を、個別返信しやすい画像とDM文章にまとめる。

## 対象

- 対象画面：管理画面のInstagram画像作成
- 対象ユーザー：管理者
- 対象外：公開画面での自動ランキング表示、Instagramへの自動送信

## 期待する挙動

1. 対象月とキャラクターを選択する。
2. 公開中のスケジュールを日別に集計し、同じタイトルを1件と数えたイベント数の多い順、次に各イベントの総件数が多い順でおすすめ日を表示する。
3. 休園日は集計から除外する。
4. 日付範囲を持つ予定は、対象月内の各開催日に1件として展開する。
5. 毎日会えるキャラクターは、明示的なファンスタジオ予定がない営業日に限り、補完用のファンスタジオ1件を加える。
6. 同じ予定は同一日に重複集計せず、イベント数と総件数の両方が同じ日は同順位で表示する。
7. 同順位で予定タイトルと各件数が同じ日は1つの順位カードへまとめ、複数の日付を表示する。1〜3位の各カード内に予定タイトルを1列でまとめ、同名タイトルの末尾へ件数を表示する。時間と場所は画像へ表示しない。2位・3位は1位より小さい日付・予定フォントを使う。
8. キャラクター名付きのファンスタジオグリーティングを含め、タイトルに「ファンスタジオ」を含む予定は「ファンスタジオ」へ統合する。
9. 1080×1350pxのPNG、DM文章、キャラクター・月指定済みスケジュールURLを作成する。
10. DM文章は推しキャラクター名、同率を含むおすすめ日、詳細URL、予定変更の注意書きだけで簡潔に構成する。

## 状態

| 状態 | 表示・操作 |
| --- | --- |
| loading | 最新データの読み込み中であることを表示する |
| empty | 対象月に掲載中の登場予定がないことを表示し、画像保存を無効にする |
| error | 保存済みデータで集計していること、または休園日確認が必要なことを表示する |
| populated | 上位3グループ、各順位の予定内訳、画像・DM文章・絞り込みURLを表示する |

## データ

- 正本：Supabaseの承認済み公開スケジュール、キャラクター台帳、営業日情報
- 読み取り：既存の`useScheduleEntries`、`useCharacters`、`useParkOperatingDays`
- 変更：なし。画像と文章はブラウザ内で生成する
- 権限：管理画面へアクセスできる管理者のみ

## 受け入れ条件

- [x] 月外・対象外キャラクターの予定を含めない
- [x] 休園日、期間予定、重複、毎日会える登録、同順位をテストする
- [x] 対象月・キャラクター変更時に集計、画像、DM文章、URLが更新される
- [x] データが空の場合に誤ったおすすめ日を表示しない
- [x] 既存データを変更せず画像を生成する
