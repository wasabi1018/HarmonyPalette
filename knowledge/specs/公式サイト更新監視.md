# 公式サイト更新監視

## 目的

管理者が、ハーモニーランド公式サイトのどの領域が更新されたかをDiscord通知と管理画面で把握できるようにします。

## 対象

- 対象画面：`/admin/official-updates`
- 対象ユーザー：Harmony Palette管理者
- 対象領域：お知らせ一覧、ハーモニーランドのスケジュール、ファンスタジオのスケジュール
- 対象外：公式サイト全ページの汎用変更監視、スケジュールの自動取り込み・自動公開

## 期待する挙動

1. 1回の監視で検出した変更を、領域別に1件の更新履歴へ集約する。
2. 複数領域が変わった場合は「お知らせ一覧とファンスタジオのスケジュールが変更されました。」のように、更新領域を列挙する。
3. 各領域には追加・変更・削除候補・要確認の件数を表示する。
4. スケジュール変更には対象日を表示する。
5. お知らせ変更には、取得できる範囲で追加・変更・削除候補のタイトルと公式URLを最大5件表示する。
6. Discord通知は監視1回につき1件とし、管理画面と同じ領域、件数、対象日、見出しを表示する。
7. 原本のハッシュだけが変わり、正規化後のスケジュール内容に意味差分がなければ通知しない。
8. 初回実行は基準データを保存し、更新通知を送らない。
9. 検出結果は通知と確認にのみ使い、自動取り込み・自動公開しない。
10. Fan Studioの複数日が更新された場合、対象日をまとめて1回のOCR処理で確認する。
11. Fan StudioのOCRに失敗した場合も、お知らせなど他領域の通知を止めず、Fan Studioは対象日を「要確認」として同じ通知に含める。

## 状態

| 状態 | 表示・操作 |
| --- | --- |
| loading | 実行・保存・通知中の操作を無効化し、処理中表示にする |
| empty | 更新履歴がないことを表示する |
| error | 監視設定、公式取得、Discord送信のエラーを表示・記録する |
| populated | 更新領域、件数、対象日、見出し、確認状態を表示する |

## データ

- 正本：公式取得原本は`official_source_states`と`official_source_versions`、監視履歴は`official_update_events`
- 読み取り：サーバー専用Repositoryから管理画面とDiscord通知へ渡す
- 変更：集約内容は`official_update_events.metadata.sections`に保存する
- 権限：管理APIは既存のインポート認可を必須とする

## 受け入れ条件

- [x] お知らせとFan Studioが同時に変わると、両方を列挙した通知が1件作られる
- [x] 同じ領域の複数日変更は、領域を重複させず対象日と件数を集約する
- [x] お知らせの追加・変更・削除候補を判定できる
- [x] 既存の更新履歴を引き続き表示できる
- [x] 意味差分がないスケジュール変更では通知しない
- [x] Fan Studioの複数日変更を1回のOCR処理にまとめる
- [x] Fan StudioのOCR失敗時も他領域を通知し、対象日は要確認として記録する
- [x] 自動取り込み・自動公開を行わない
