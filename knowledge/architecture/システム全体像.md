# システム全体像

Harmony Paletteは、Next.js App Routerで公開サイトと管理画面を提供し、Supabaseを承認済み運用データの正本として利用するWebアプリケーションです。

```text
利用者のブラウザ
  ├─ 公開サイト app/(site)
  ├─ My Plan components + lib/daily-plan-store.ts
  └─ 管理画面 app/admin/(protected)
             │
             ▼
Next.js ページ / Route Handler / Middleware
             │
             ▼
lib/supabase・lib/articles・lib/official-import
             │
             ▼
Supabase Database / Auth / Storage
```

## 主な領域

| 領域 | 責任 | 主な場所 |
| --- | --- | --- |
| 公開サイト | トップ、スケジュール、My Plan、記事、ガイド | `app/(site)/` |
| 管理画面 | 記事、画像、予定、シリーズ、タグ、分析、Instagram設定 | `app/admin/(protected)/`、`components/admin/` |
| API | 公開取得、管理変更、Cron | `app/api/` |
| 共通UI | 公開画面とインタラクション | `components/` |
| ドメインロジック | 予定、My Plan、記事、分析、表示変換 | `lib/` |
| データ境界 | ブラウザ、サーバー、認証、Repository | `lib/supabase/` |
| 公式取り込み | PDF・画像取得、OCR、正規化、候補生成 | `lib/official-import/` |
| DB履歴 | テーブル、RLS、関数、インデックス | `supabase/migrations/` |
| 運用スクリプト | インポート、Seed、画像生成、検査 | `scripts/` |
| QA証跡 | 画面比較、判断、生成物確認 | `audit/`、`design-qa.md` |

## 重要な境界

- ブラウザへ渡せるのは`NEXT_PUBLIC_`で始まる公開用環境変数だけです。
- Secret Keyを使う処理はサーバー側に限定します。
- 管理画面と管理APIはSupabase Authおよび管理者判定で保護します。
- 公式データは取得結果を直接公開せず、候補・レビュー・公開の段階を維持します。
- My Planのクライアント状態と、Supabaseに保存する承認済み運用データを混同しません。
