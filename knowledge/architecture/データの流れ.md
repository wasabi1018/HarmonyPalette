# データの流れ

## 公式スケジュール

```text
公式サイト・PDF・画像
  → PDF.js / napi-rs/canvas
  → Sharpによる画像前処理
  → 必要に応じてTesseract.jsでOCR
  → lib/official-importで正規化
  → 候補・差分・レビュー
  → 明示的に承認された永続化
  → Supabase
  → Repository / Route Handler
  → 公開スケジュール・My Plan
```

不確かな時刻、キャラクター、休止情報を事実として補完しません。取得元URLと対象日を追跡可能にします。

## 記事

```text
管理画面のTiptapエディター
  → 入力検証・sanitize-html
  → 記事本文とメタデータ: Supabase Database
  → 画像: Supabase Storage
  → 公開条件の確認
  → Next.js記事ページ・フィード・シリーズ
```

下書き、予約、公開、改訂、ゴミ箱、復元、完全削除の状態を保持します。

## My Plan

```text
公開スケジュール・ユーザー作成予定
  → lib/daily-plan-store.ts
  → components/daily-plan-builder.tsx
  → dnd-kitで並べ替え
  → html-to-imageで画像書き出し
```

公式予定とユーザー作成予定では編集可能な項目が異なります。

## 認証付き管理操作

```text
/admin または /api/admin
  → middleware.ts
  → Supabase SSRでセッション更新
  → lib/supabase/auth-server.tsで管理者判定
  → サーバー側Repository / Route Handler
  → Supabase
```

秘密鍵、管理者判定、権限付き変更をClient Componentへ移しません。
